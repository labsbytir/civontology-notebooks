# Welcome to Civontology Notebook

This is a public digital garden built with **Astro + Starlight**.

## Features

- ✅ **Dark mode** (black theme) + **Light mode**
- ✅ **Sticky header** with search
- ✅ **Giscus comments** on every page
- ✅ **Community forum** powered by GitHub Discussions
- ✅ **Fast search** with Pagefind
- ✅ **Auto-generated sitemap**
- ✅ **SEO optimized** with schema markup
- ✅ **LLM-friendly** with llms.txt

## Built with

- [Astro](https://astro.build/) - The web framework
- [Starlight](https://starlight.astro.build/) - Documentation theme
- [Giscus](https://giscus.app/) - Comments via GitHub Discussions
